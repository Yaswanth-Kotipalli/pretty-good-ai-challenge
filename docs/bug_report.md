## Method

Each call was placed by an LLM-driven patient simulator (LiveKit Agents pipeline:
Deepgram STT → GPT-4o-mini → OpenAI TTS) calling +1-805-439-8008 from a single
Twilio number. Transcripts were captured from the live session and recordings
downloaded from Twilio. Findings below were extracted by an LLM QA pass over the
transcripts and spot-checked against the audio.

Severity guide: **high** = wrong outcome for the patient (wrong booking, missed
urgency, safety issue); **medium** = goal achieved but with friction, confusion,
or avoidable delay; **low** = polish note.
